JUSTCARD V15 - SIMPLE WEB VERSION

This version is designed to run as a normal website.
NO START_WINDOWS.BAT is required for users.

Deployment:
1. Upload this project to Vercel.
2. Add an Environment Variable:
   REMOVE_BG_API_KEY = your NEW Remove.bg API key
3. Deploy.
4. Open your website normally.

Photo Maker:
Upload -> Crop -> Remove BG -> White/Custom Background -> Download

The API key is kept on the server and is NOT exposed in browser JavaScript.
Do not put the key directly into index.html.
